# Personal Portfolio Website

A modern, responsive personal portfolio website showcasing professional skills, projects, and contact information. Built with HTML, CSS, and JavaScript following best practices and modern web development standards.

## 🌟 Features

### Core Functionality
- **Responsive Design**: Mobile-first approach with breakpoints for all device sizes
- **Sticky Navigation**: Smooth scrolling navigation that stays visible while scrolling
- **Interactive Elements**: Hover effects, animations, and transitions throughout
- **Form Validation**: Client-side validation for contact form with error handling
- **Project Filtering**: Interactive project gallery with category filtering
- **FAQ Accordion**: Expandable/collapsible FAQ section
- **Dark Mode Support**: CSS-based dark theme support

### Pages Included
1. **Home (index.html)** - Main landing page with hero section and skills overview
2. **About (about.html)** - Professional background, experience timeline, and skills
3. **Projects (projects.html)** - Portfolio gallery with filtering and pricing packages
4. **Contact (contact.html)** - Contact form with validation and business information

### CSS Concepts Implemented
- ✅ **Box Model** - Proper use of margin, padding, border properties
- ✅ **Flexbox Layout** - Navbar, cards, and responsive layouts
- ✅ **CSS Grid** - Main layouts, gallery, and pricing sections
- ✅ **Position Properties** - Sticky navbar, absolute positioning for badges
- ✅ **Media Queries** - Responsive breakpoints for mobile, tablet, and desktop
- ✅ **Animations** - Hover effects, transitions, keyframe animations
- ✅ **Pseudo-classes** - `:hover`, `:focus`, `:nth-child`, `:active`
- ✅ **CSS Variables** - `:root` variables for consistent theming
- ✅ **Responsive Units** - `%`, `rem`, `vw`, `vh` for scalable layouts

## 🛠️ Tech Stack

- **HTML5** - Semantic markup and accessibility
- **CSS3** - Modern styling with Flexbox, Grid, and animations
- **JavaScript** - Interactive functionality and form validation
- **Font Awesome** - Icon library for social media and UI elements
- **Google Fonts** - Typography (Segoe UI font stack)

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Text editor (VS Code, Sublime Text, etc.)

### Installation
1. Clone or download this repository
2. Open `index.html` in your web browser
3. Navigate through the different pages using the navigation menu

### Development
To modify the portfolio:
1. Edit HTML files for content changes
2. Modify `styles.css` for styling updates
3. Update `script.js` for JavaScript functionality
